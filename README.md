# المصحف المرتل المتزامن · Tarteel Sync
### تطبيق ويب تفاعلي متزامن بالكلمات مدعوم بـ mp3quran API v4 (Staging Preview)

تطبيق ويب قرآني فائق السرعة والأناقة، يستعرض الإمكانيات الثورية للنسخة التجريبية الجديدة من **mp3quran.net API v4**، وأهمها: **تظليل الكلمات لحظيًا مع الصوت بدقة المللي ثانية** والتنقل التفاعلي بالنقر على أي كلمة.

---

## ✨ المميزات الرئيسية

1. **تزامن الكلمات اللحظي (Word-by-Word Live Highlight)**:
   - متابعة الكلمة المقروءة بتوهج ذهبي انسيابي متناسق مع سرعة التلاوة.
   - يعتمد على بيانات المحاذاة الصوتية المنشأة بنموذج `Zipformer` من مشروع `QuranLab`.

2. **التنقل التفاعلي بالنقر (Interactive Seek)**:
   - انقر على أي كلمة في الآية للانتقال فورًا إلى لحظة نطقها والبدء بالاستماع منها.
   - انقر على رقم الآية للاستماع إليها من بدايتها.

3. **دعم جودات وصيغ صوتية متعددة عبر CDN**:
   - التبديل الفوري بنقرة زر بين:
     - **أصلية (Original / MP3 High)**.
     - **MP3 64kbps** (توفير استهلاك البيانات والسرعة).
     - **Opus 48kbps** (أعلى كفاءة ضغط وجودة حديثة).
   - دعم كامل لـ `Byte-Range Requests` للتنقل اللحظي دون إعادة تحميل الملف.

4. **مستكشف القراء والروايات**:
   - تصفح وبحث فوري في **297 قارئًا** مع التسامح في الهمزات والحركات.
   - فلترة القراء بحسب دعم التزامن اللحظي، أو الرواية (حفص، ورش، قالون، الدوري...).
   - إمكانية اختيار الرواية أو النمط (مرتل / مجود) للقارئ.

5. **أداة معايرة التوقيت وتوليد تقارير الملاحظات (Feedback Tool)**:
   - مزلجة ضبط إزاحة التزامن (`Sync Offset`) بدقة `±300ms` لاختبار دقة التوقيتات.
   - زر **"نسخ تقرير التوقيت للملاحظات"** يولد تقريرًا جاهزًا بنقرة واحدة للمشاركة في مجتمع إتقان للمطورين.

6. **تصميم قرآني فاخر ومريح للعين**:
   - خط مصحف المدينة النبوية الشريف الأصيل (KFGQPC Uthmanic Hafs).
   - نمط داكن رخامي فاخر مع إمكانية التبديل إلى نمط الورق القرآني الهادئ (Sepia).
   - تمرير تلقائي ذكي يتبع تلاوة القارئ بسلاسة.
   - اختصارات لوحة المفاتيح: مسافة (تشغيل/إيقاف)، الأسهم (تنقل بالكلمات)، `[` و `]` (معايرة التزامن).

## 🚀 كيفية التشغيل

التطبيق جاهز ومبني بدون أي أطر ثقيلة (Pure Native HTML5 / CSS3 / ES6 Vanilla JS):

1. **عبر الخادم المحلي المدمج**:
   ```bash
   node server.js
   ```
2. افتح المتصفح على الرابط:
   [http://localhost:3000/](http://localhost:3000/)

أو تشغيله مباشرةً عبر Laragon من خلال فتح:
[http://localhost/Itqan_Projects/MP3NEW/](http://localhost/Itqan_Projects/MP3NEW/) (عند تشغيل Apache).
